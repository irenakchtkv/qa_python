# Sprint_4

## Реализованные тесты для класса BooksCollector:

- test_add_new_book_add_two_books (проверяет добавление двух книг в словарь)
- test_add_new_book_does_not_add_book_with_invalid_name_length (проверяет, что книги с недопустимой длиной в названии не добавляются в словарь)
- test_set_book_genre_sets_genre (проверяет установку жанра книги)
- test_get_book_genre_returns_correct_genre (проверяет получение жанра книги)
- test_get_books_with_specific_genre_returns_list_with_chosen_genre (проверяет получение списка книг выбранного жанра)
- test_get_books_genre_returns_books_genre_dictionary (проверяет получение словаря с книгами и жанрами)
- test_get_books_for_children_returns_list_with_books_for_children (проверяет получение списка книг для детей)
- test_add_book_in_favorites_book_added_to_favorites_list (проверяет добавление книги в избранное)
- test_delete_book_from_favorites_removes_book_from_the_list (проверяет удаление книги из избранного)
- test_get_list_of_favorites_books_returns_favorites_list (проверяет получение списка избранных книг)
